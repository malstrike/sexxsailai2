## ⚡ Overview

This is the official digital landing interface for **Sexxsail**. Designed as a single-page application (SPA) focusing on high-fidelity UI, smooth glassmorphism effects, and direct encrypted communication channels.

**Live Link:** [t.me/sexsei1s](https://t.me/sexsei1s)

## 🛠 Tech Stack

*   **Core:** React 19
*   **Styling:** TailwindCSS
*   **Icons:** Lucide React
*   **Animation:** CSS3 Keyframes & Custom Canvas

## 🚀 Features

*   **Glitch/Cyberpunk Aesthetic:** Custom fonts and neon gradients.
*   **Interactive Background:** HTML5 Canvas particle system.
*   **Glassmorphism:** High-end blur and transparency effects.
*   **Responsive:** Fully optimized for mobile and desktop terminals.

## 📦 Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/sexxsail-portfolio.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run local server:
    ```bash
    npm start
    ```
